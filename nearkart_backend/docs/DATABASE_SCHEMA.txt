================================================================================
  CASCADE DELETE BEHAVIOR
================================================================================

  Delete auth_users  →  deletes: auth_otp_tokens, auth_device_tokens,
                                  store (and everything under it), store_follows,
                                  store_reviews, wishlists, videos_videolike

  Delete stores      →  deletes: store_hours, store_follows, store_reviews,
                                  products (and variants/images/wishlists),
                                  videos_video (and videolike rows)

  Delete products    →  deletes: product_variants, product_images, wishlists

  Delete videos_video →  deletes: videos_videolike rows for that video

================================================================================
  SPECIAL COLUMN NOTES
================================================================================

  GEOGRAPHY vs GEOMETRY:
    stores.location          → GEOGRAPHY(Point,4326)  uses geography=True
                                DWithin in km works without unit conversion
    auth_users.registered_location → GEOMETRY(Point,4326)  plain spatial
    videos_video.location    → GEOGRAPHY(Point,4326)  copied from store

  UUID vs BIGSERIAL primary keys:
    UUID PK  → auth_users, auth_otp_tokens, auth_device_tokens, stores,
               store_follows, store_reviews, products, product_variants,
               product_images, wishlists, videos_video
    BIGSERIAL PK (integer) → store_hours, videos_videolike
                              (Django default when no explicit PK defined)

  Atomic counters (never use SELECT+UPDATE — always F() expressions):
    videos_video.view_count   → F('view_count') + 1 on every GET /videos/<id>/
    videos_video.like_count   → F('like_count') + 1 on like, - 1 on unlike

  Auto-populated columns (set in model save(), not by caller):
    videos_video.expires_at   → now() + VIDEO_EXPIRY_DAYS (default 30 days)
    videos_video.location     → copied from stores.location at create time
    videos_video.locality     → copied from stores.locality at create time
